# Changelog

## [0.1.0] — 2026-02-22

### Added
- `@occums` chat participant for Copilot Chat
- Automatic model selection using Occam's Razor principle
- Task analyzer with 6 capability dimensions (reasoning, creativity, knowledge, code, context, precision)
- Built-in profiles for GPT-4o, GPT-4o Mini, Claude Sonnet, Claude Haiku, Claude Opus, Gemini Flash, Gemini Pro, o1, o1-mini, o3
- Status bar widget showing recommended model for current context
- `Ctrl+Shift+R` / `Cmd+Shift+R` — quick ask with auto model selection
- `Ctrl+Shift+Alt+R` / `Cmd+Shift+Alt+R` — ask about selected code
- `/models` command — list all available Copilot models
- `/analyze` command — dry-run task analysis
- `/config` command — show configuration
- Configurable simplicity weights (cost, speed, size)
- Provider preference setting
- Auto-fallback when selected model errors
- Welcome notification on first activation
